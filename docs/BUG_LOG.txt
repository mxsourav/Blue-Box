 BUG #001 — [MEDIUM] [OPEN] — nRF24 Radio1 Pin Conflict
──────────────────────────────────────────────────────────────────────────────
 DATE FOUND    : 2026-06-02
 VERSION       : v1.0.0
 DESCRIPTION   : GPIO 10 and GPIO 11 are now assigned to BTN_BACK and
                 BTN_SELECT respectively, but the nRF24 radio1 module
                 still defines CE1_PIN=10 and CSN1_PIN=11.
 REPRODUCTION  : Attempt to use nRF24 radio1 features while buttons
                 are also active — pin contention will occur.
 EXPECTED      : Buttons and nRF24 radio1 work independently.
 ACTUAL        : Both peripherals share the same GPIO pins.
 WORKAROUND    : Avoid using nRF24 radio1 features, or reassign
                 CE1/CSN1 to free GPIOs if available.
 ASSIGNED TO   : —
 NOTES         : radio2 (CE2=12, CSN2=13) is unaffected.
